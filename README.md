# Beats Learning Project

A responsive, single-page learning platform landing page built with HTML and CSS.

## Live Demo

https://nafiz-365.github.io/Beats-Learning-Project/

## Features

- Modern and responsive landing page layout
- Hero, course, services, and newsletter sections
- Mobile navigation toggle
- Clean typography using Google Fonts
- Icon support with Font Awesome

## Tech Stack

- HTML5
- CSS3

## Project Structure

```text
Beats-Learning-Project/
├── index.html
└── assets/
    ├── style.css
    └── images...
```

## Run Locally

1. Clone the repository.
2. Open `index.html` in your browser.
