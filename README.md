# Beats Learning Project

A modern and responsive landing page for an online learning platform called **Beats Learning**.

## Live Demo

Visit the project here:  
https://nafiz-365.github.io/Beats-Learning-Project/

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation with mobile menu toggle
- Hero, about, services, courses, trial, newsletter, and footer sections
- Clean UI with gradients, cards, and subtle animations

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## Project Structure

```text
Beats-Learning-Project/
├── index.html
└── assets/
    ├── style.css
    └── images and icons
```

## Run Locally

1. Clone the repository.
2. Open `index.html` in your browser.
